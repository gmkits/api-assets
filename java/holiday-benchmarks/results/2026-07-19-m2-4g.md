# 4 GiB JMH result — Apple M2

Environment:

- Apple M2, 8 logical CPUs, 16 GiB host memory
- BellSoft Liberica JDK 8.0.492 and JDK 25.0.3 LTS
- JMH 1.37, G1 GC, `-Xms4g -Xmx4g`
- 3 × 2 s warm-up, 5 × 3 s measurement, one fork
- External unified assets: `data/date-assets`

| Benchmark | Threads | JDK 8 ops/s | JDK 25 ops/s |
| --- | ---: | ---: | ---: |
| `singleDay` | 1 | 47,939,343 | 40,961,043 |
| `isHoliday` | 1 | 50,928,242 | 39,346,989 |
| `month` | 1 | 33,784,491 | 27,160,196 |
| `countWorkdaysForYear` | 1 | 4,105,917 | 4,242,828 |
| `concurrentMixedQueries` | 8 | 3,129,092 | 3,510,996 |

These are in-process engine operations, not HTTP QPS. `concurrentMixedQueries`
performs four service calls per benchmark operation. JMH selected a full
blackhole on JDK 8 and a compiler blackhole on JDK 25, so cross-JDK comparisons
are directional rather than a strict JVM shootout.

Command:

```bash
java -Dcn.holiday.assets.path=/absolute/path/data/date-assets \
  -jar holiday-benchmarks/target/benchmarks.jar
```
